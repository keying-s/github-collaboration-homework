# 余烬协议：先把一间房做得值得再玩一次

## 想让玩家获得什么感受

开火立即有反馈；身陷包围时，仍能通过走位、闪避和环境解围；拿到一个技能后，自然想试试它和手上的枪会发生什么。

“90 分”是品质目标，不能通过功能清单保证。这个原型先检验射击手感、战斗决策和组合变化，之后用真人试玩决定投入方向。

## 核心循环

准备 → 满状态进入房间 → 清除两波有分工的敌人 → 拾取枪械与技能 → 传送至下一关 → Boss 检验当前组合 → 完成或失败重开。

每场行动推荐未来控制在 8–12 分钟。当前四关是较短的框架切片，具体时长随打法变化，尚未经过真人样本测量。

不设经济系统，把选择集中到战斗中：此时换弹还是闪避？拿高风险的近身爆发，还是控制技能？先处理远程怪，还是射爆桶清掉追兵？

## 三个设计支柱

### 1. 好的射击需要可以读懂的风险

- 游骑兵精准稳定，适合中远距离边走边射；焚化者用锥形火焰换取贴脸的高群体收益——开局二选一定义整局构筑。
- 闪避带短暂无敌，有冷却，不能连续无脑使用；技能可以让闪避成为进攻手段。
- 近战怪逼迫移动，远程怪压缩空间，重甲怪用明显预警的冲锋打乱站位。
- 敌方子弹采用粉红色球体，玩家子弹采用细亮弹道，避免在混战中混淆。
- 掩体阻挡双方弹道；爆炸桶伤害敌我，提供清群机会和位置风险。

### 2. 技能改变行为，枪械决定表达方式

| 组合                | 鼓励的打法                         |
| ------------------- | ---------------------------------- |
| 霰弹枪 + 连锁电弧   | 靠近密集敌群，一次散射触发多段群伤 |
| 脉冲枪 + 霜冻弹芯   | 快速给多目标挂减速，控制侧翼       |
| 突击步枪 + 贯穿弹道 | 利用通道和追击队列获得弹药效率     |
| 闪避新星 + 战地修复 | 冲刺清掉近身残血，用击杀恢复状态   |
| 过载机匣 + 贯穿弹道 | 以走位承担防御，用持续压制换空间   |

随机三选一只包含未拥有技能，同一次选择期间保持稳定。四个模块在最终 Boss 前可以集齐。首版不引入复杂稀有度、元素相克或几十种同质加成。

### 3. 组队应该产生互补

本版用 AI 支援观察双单位的可读性和节奏。它不会倒地，暂不能验证救援或真人协作的乐趣。

真正的 2–4 人版本优先考虑：控制与爆发互补、掩护换弹、倒地救援、同步集火精英、可以转交的枪械。先让协作来自战场，再考虑固定职业。多人难度应更多调整敌人组合与攻击方向，避免纯粹堆高血量。

## “每关初始固定”的具体解释

当前新行动统一 100 生命与突击步枪；每关恢复生命、弹匣、闪避，保留本次行动中得到的武器和技能。这使前一关的选择在后面有意义，也避免资源耗尽使后面几关失去机会。没有金币、商店或永久数值强化。若希望每关连装备也重置，可以在关卡准备函数中统一改动。

## 为什么这次使用 Phaser + TypeScript

当前目标是迅速得到能发链接、方便反复修改的俯视角 2D 原型。Phaser 提供浏览器渲染、输入、场景、时间与基础特效，TypeScript 约束数据和模块边界，Vite 负责开发与静态构建。模拟逻辑独立于 Phaser，后续替换美术或引入多人同步时，核心规则仍有明确归属。

官方资料：[Phaser 文档](https://docs.phaser.io/)、[Phaser 项目说明](https://github.com/phaserjs/phaser)。

这不是承诺所有发行目标都用同一套技术。若后续目标明确转为重度原生主机 / 桌面发行，应该在增加大量内容前重新评估工具链；当前不为尚未确认的平台提前重写。

## 多人实现边界

当前单机模型不是已经完成的网络层。后续应让服务器权威执行战斗规则，客户端发送输入并做本地预测，服务器发送快照与确认。加入断线恢复、房间生命周期与延迟模拟测试。现在的事件层和纯模拟层有助于迁移，但仍需要固定步长、序列化、预测回滚和网络工程。

## 下一轮试玩最值得观察的事

1. 不解释规则时，玩家能否在 30 秒内理解开火、闪避和拾取？
2. 三把枪是否让人改变距离和节奏，而不是只看伤害大小？
3. 第一次技能选择之后，玩家能否说出“我的打法变了什么”？
4. 受伤是否有可读的原因，闪避成功是否可感知？
5. 完成或失败后，玩家是否主动再开一次，而非被要求继续？

建议先找 5–10 位目标玩家各玩两局，记录卡点、死亡原因、选择和自发重开情况；这些是后续投入的依据，不是已经达到的成绩。

## 优先级

- 下一步：依据试玩调整反馈、怪物密度、枪械差异和技能协同；完善 Boss 预警与可惩罚窗口。
- 再下一步：实现两名真人的稳定联机与救援，再验证是否值得扩至四人。
- 核心循环成立后：增加手工房间池、精英词缀、房间路线选择、音乐和完整美术。
- 暂不做：金币商店、大型背包、任务墙、日常打卡、局外数值碾压。

## 快速开始（单机）

1. 双击 `start.bat`（或自己起个静态服务器：`python -m http.server 8137`）
2. 浏览器打开 http://localhost:8137
3. 输入昵称 → 点 **「单人练习（对战机器人）」**，和 7 个机器人打 4v4 团队死斗

> 需要联网加载 Three.js 引擎（CDN），首次打开稍等几秒。

## 联机对战（无需服务器原理）

游戏使用 **WebRTC P2P 直连**：

- 房主点 **「创建联机房间」** → 得到一个 5 位房间码（页面左上角会显示）
- 把房间码发给朋友（微信/QQ 都行）
- 朋友打开**同一个游戏页面**，输入房间码点 **「加入房间」**
- 数据在玩家浏览器之间直连传输，信令走 PeerJS 免费公共服务器，**零成本、无需公网 IP**

限制（P2P 方案的天然代价）：

- **房主的页面必须保持打开**（房主浏览器就是"服务器"），房主关页面 = 房间解散
- 极少数严格 NAT 网络下可能打洞失败（表现为一直"正在连接"）
- 最多 8 人

## 朋友怎么打开游戏页面？（两种方式）

### 方式一：发文件（最简单，零门槛）

把根目录下的 **`双击即玩-CLASS-STRIKE.html`**（约 74KB）直接微信/QQ 发给朋友，
朋友下载后**双击用 Chrome 或 Edge 打开**就能玩 —— 不用装 Python、不用访问任何网站。
（改代码后重新生成：`node build_single.js`）

### 方式二：发布成公网网址（推荐长期用）

把整个文件夹（除 js 外其实只需 index.html + js/）拖到免费静态托管上，得到一个
https 网址发给朋友。国内访问速度对比：

| 平台 | 国内访问 | 说明 |
|---|---|---|
| **EdgeOne Pages（腾讯）** | ✅ 流畅直连，推荐 | 拖拽文件夹即可发布，免费，无需备案（默认域名） |
| Cloudflare Pages | ⚠️ 时好时坏 | 免费无限流量 |
| GitHub Pages / Netlify | ⚠️ 慢且不稳定 | 海外节点 |
| Vercel | ❌ 大陆基本不通 | 不推荐 |

## 规则

- **团队死斗**：T（恐怖分子）vs CT（反恐精英），先到 **30 杀** 的队伍获胜，8 秒后自动开新局
- 爆头 ×4 伤害；移动/跳跃开枪散布变大；无队友伤害
- 阵亡 3 秒后在己方出生点重生

## 技术栈

- Three.js r160（3D 渲染，CDN 加载）
- PeerJS 1.5（WebRTC P2P 联机，公共信令 + STUN 打洞）
- Web Audio API 程序合成音效（零音频素材）
- 纯静态文件，无构建步骤

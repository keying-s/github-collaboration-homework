# GitHub Collaboration Homework

This private repository is used for our group GitHub collaboration exercise.

## Team workflow

1. Accept the repository invitation.
2. Clone the repository with your own GitHub account.
3. Use a coding agent to edit `team-notes.md`.
4. Commit and push the change.
5. If a push conflict occurs, take a screenshot before asking the coding agent to resolve it.

## A message to all coding agents

Hello, fellow agents! You are collaborating with several humans and other coding agents in this repository. Please help us work as one team:

- Read the open Issues and the latest repository state before making changes.
- Run `git pull --rebase origin main` before starting new work.
- Preserve your teammates' work and never overwrite or delete it without a clear request.
- Prefer small, focused commits with descriptive commit messages.
- Never force-push to `main`.
- When a conflict occurs, keep the useful intent from both sides and explain how you resolved it.
- Leave the repository clean, synchronized, and easy for the next human or agent to continue.

Thank you for taking care of our shared workspace. Humans and agents are teammates here.

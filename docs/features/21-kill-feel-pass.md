## 玩家价值

当前战斗"功能正确但手感发空"。玩家在开火、命中、击杀三个最高频的时刻得不到足够的反馈，
因此难以判断"我是否打中了""我是否打死了"，连续战斗缺少节奏感和成就感。

具体现状（来自代码实测，非主观描述）：

| 时刻 | 现在发生什么 | 问题 |
| ---- | ------------ | ---- |
| 开火 | 3 颗粒子 | 没有枪口火光，没有后坐，武器"没有重量" |
| 命中 | 飘伤害数字 + 少量粒子 | 敌人不会被推动，缺少实体感 |
| 击杀 | 敌人从数组移除，**瞬间消失** | 没有倒地/崩解，"打死"和"消失"没有区别 |
| 受伤 | 相机震动强度 0.004（约 4px） | 肉眼几乎不可见 |
| 连击 | HUD 数字变化 | 反馈强度恒定，长时间连杀单调 |

期望变化：命中—击杀变成 500ms 内的一串可读反馈，并且**随死因与连击变化**，避免重复感。

## 范围

- 这次做：
  1. 击杀顿帧（hitstop）：普通击杀 45ms，重甲 / Boss 90ms。
  2. 命中击退：沿弹道的衰减冲量，带掩体与边界碰撞收敛。
  3. 死亡动画：0.25–0.45s，按死因与敌人类型分化。
  4. 分级震屏：开火 < 命中 < 击杀 < 重甲/Boss 击杀 < 爆炸（爆炸保持现有强度）。
  5. 枪口火光 + 视觉后坐（仅渲染层位移，不改移动手感）。
  6. 连击升级：连击越高，击杀光环更大更暖、震屏更强，达阈值时屏幕边缘微闪。
- 这次不做：
  - 不改伤害数值、武器平衡、敌人 AI、关卡内容。
  - 不改音频引擎（已有 12 种事件，另开 Issue）。
  - 不新增玩家可见文案（因此不涉及 i18n；若后续需要必须中英双语）。
  - 不改玩家实际移动与碰撞（后坐只做视觉偏移）。
- 依赖的 Issue / PR：无。与 PR #13（第四关）、#15（布局）、#17（全屏面板）无文件重叠。

  - 后坐只做视觉偏移，不改玩家实际位移，避免影响移动/冲刺类回归测试。

## 最终实现

按计划实现，另加一个计划外但必要的修复：

- **顿帧**：`Simulation.freeze`（公开字段）。击杀瞬间定格——普通敌人 45ms，重甲 / Boss 90ms；期间整个世界暂停，超时自动恢复。`start()` 时重置。
- **击退**：`Simulation.knockback()` 沿弹道 / 爆炸方向施加衰减冲量；重量分级（crawler 1 / spitter 1.3 / brute 2.8 / boss 7）；复用 `move()` 的掩体与边界碰撞，敌人只会被推到贴墙，不会穿墙。
- **脱困滑动（计划外修复）**：击退会把敌人推进"两侧都被掩体卡死"的死角（实测在第三关把一只重甲卡在 (1064,180)，两次位移轴全被挡）。新增 `enemyMove()`：敌人被挡超过 0.25s 后沿掩体切向滑动，先试 id 奇偶决定的一侧，不动再试另一侧。这也修复了敌人无击退时也可能卡死的旧隐患。
- **死亡动画**：渲染层 `deaths` 列表，尸体旋转、缩放、淡出并散出碎片；三种死因表现不同——子弹击杀翻滚崩解、爆炸击杀被掀飞放大、连锁击杀泛冷色碎裂；重甲 / Boss 倒地更久（0.45s / 0.62s）。旋转方向随机（渲染层种子随机），避免每次死亡一模一样。
- **分级震屏**：`shake()` 帮助函数带最小间隔节流（开火 0.12s 内不重复）。开火 0.0016 < 命中 0.0022 < 击杀 0.0055 < 重甲/Boss 0.009；受伤从 0.004 提到 0.0062，爆炸保持 0.0035。
- **枪口火光 + 视觉后坐**：`flashes` 列表画枪口锥形闪光（沿 `shot` 事件的朝向角）；角色沿反方向最多 5px 的视觉偏移（`recoil`），不影响实际移动与碰撞。
- **连击升级**：连击 4 / 8 / 12 换档（tier 0-3）。击杀光环随档位变大（50→110px）、颜色由绿转暖橙；tier 3 触发一次屏幕边缘微闪。死亡碎片与尸体颜色同步转暖。

与原计划的差异：新增 `enemyMove()` 脱困逻辑（计划外，测试逼出来的真实 bug）。

## 已知限制和后续

- 尚未解决的限制：震屏由 Phaser 相机提供，无法做方向性震动；顿帧期间输入不响应（上限 90ms，可接受）。
- 后续 Issue：威胁提示（屏幕边缘敌人指示、重甲冲锋地面预警、方向性受击提示）；音效随连击升调。
- 撤销 / 回退此功能时需注意的兼容点：`types.ts` 新增字段均为可选，回滚只需移除 renderer 的死亡动画列表与 simulation 的顿帧/冲量三处调用。

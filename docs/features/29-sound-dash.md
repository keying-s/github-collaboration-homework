## 玩家价值

游戏本体在 #10 已加入背景音乐与基础音效（射击 / 击杀 / 爆炸 / 闪避 / 受击 / 拾取等），但战斗仍有一处“无声”的空洞：

- 子弹**命中敌人**已经产生粒子与伤害数字，却没有声音，打击感单薄。
- **连击**升到 4 / 8 / 12 层时只改颜色与光环，没有递进音效，玩家难以“听”到自己进入高热状态。
- **低血量（< 30% HP）**既没有提示音也没有心跳，危机感不足。

闪避（Shift / 空格，带 ~0.32s 无敌帧）机制已在 `main` 中实现，但玩家缺少“可用 / 冷却中”的视觉提示，难以发现与养成。

本功能补全上述三处音效，并给玩家身上加一圈“闪避就绪 / 冷却”指示环，让核心机制更易读，整体更“活”。

## 范围

- 这次做：
  - `audio.ts`：新增 `hit` 命中打击音（噪声瞬态 + 低频体感，已限流避免连射变噪音）。
  - `audio.ts`：新增 `playCombo(tier)` 连击升级音（4/8/12 → C5/E5/G5 上行）。
  - `audio.ts`：新增 `playHeartbeat()` 低血量“lub-dub”心跳。
  - `renderer.ts`：击杀时若连击层级上升则播放升级音。
  - `renderer.ts`：战斗中 HP < 30% 时周期性播放心跳 + 轻微红边闪烁。
  - `renderer.ts` + `scene.ts`：玩家周围加闪避就绪（呼吸光环）/ 冷却（进度弧）指示环。
- 这次不做：
  - 不改动闪避机制本身（位移、无敌帧、冷却、拖影、whoosh 音已在 `main`）。
  - 不新增背景音乐曲目或乐器。
  - 不做武器/技能系统的音频差异。
- 依赖的 Issue / PR：背景音乐与音效设置来自 #10；闪避机制来自 `main` 既有实现（非本仓库 Issue）。

## 验收条件

- [ ] 命中敌人有清脆打击音（已做 ~30ms 限流，连射不会变成噪音）。
- [ ] 连击升到 4 / 8 / 12 时各有上行音效。
- [ ] 玩家血量 < 30% 时周期性心跳“lub-dub” + 轻微红边闪烁。
- [ ] 玩家周围有闪避就绪（呼吸光环）/ 冷却（进度弧）指示。
- [ ] 原有音效、音乐、静音 / 音量设置不受影响。
- [ ] 自动测试、类型检查、构建、格式检查通过。
